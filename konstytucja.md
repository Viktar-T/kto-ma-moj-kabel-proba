# Kto ma mój kabel — konstytucja

1. Logika aplikacji jest w osobnym projekcie i nie wie, że istnieje okno.
2. Prawdziwe dane użytkowników nigdy nie trafiają do repozytorium.
3. Program nigdy nie wysyła niczego poza komputer, na którym działa.
4. Każda pożyczka ma datę; program nie zgaduje dat.
5. Interfejs po polsku, z polskimi znakami.
6. Zwróconej rzeczy nie wolno skasować — znika z listy, zostaje w historii.
